# 星澜 · STELLAR ECHO

> 一颗种子，一个宇宙。生成式环境音乐 × 实时视觉宇宙的浏览器创意工坊。
> A seed is a universe — a generative ambient music studio with a living visual cosmos, rendered entirely in your browser.

**星澜**是一颗"会呼吸的星体"：你给出一颗**种子**，它在浏览器里实时合成永不重复的环境音乐，并在画布上展开与之同源的视觉宇宙。没有一首曲子被预先写死，没有一段画面是素材——声音由 Web Audio 逐振荡器合成，画面由 Canvas 逐帧生成，一切由同一颗种子统御。

## ✨ 特性

### 🎵 生成式音乐引擎
- **零采样、全合成**：pad 铺底、钟磬琶音、贝斯、合成打击乐、旋律动机、氛围颗粒，全部由代码实时合成
- **种子驱动作曲**：13 种音阶（含平调子、波斯等异域音阶）、和声进行生成、动机"发展"系统（重复 / 倒影 / 移位 / 拉伸 / 反转），同一颗种子永远得到同一个宇宙
- **演化式呼吸**：每 8 小节自动微调亮度、轮转琶音、游移根音，音乐持续生长，永不重复
- **效果链**：生成式卷积混响（按种子生成脉冲响应）、乒乓延迟、总滤波、压缩 + 软限幅母带，声场如丝

### 🌌 实时视觉宇宙
四种与频谱共振的视觉模式：
- **星云**：视差星场 + 流场粒子云
- **涟漪**：底鼓触发、层层扩散的同心环
- **织锦**：万花筒对称图案，随乐句绽放
- **星轨**：流场驱动的拖尾彗星

九套调色板（深海 / 晨曦 / 雨林 / 星际 / 迷雾 / 极光 / 绯樱 / 余烬 / 水墨），与音乐世界同受种子统御。

### 🎛 交互
- **心境预设**：深海、晨曦、雨林、星际、迷雾——一键切换音乐气质
- **实时旋钮**：速度、密度、亮度、流动、混响、延迟、滤波、音量
- **录音导出**：将当下的宇宙录制为 **WAV** 文件留存
- **种子分享**：输入任意数字种子，或复制当前种子，与任何人复现同一个宇宙
- **键盘**：`空格` 奏响/静默 · `R` 新宇宙 · `E` 呼吸开关

## 🚀 运行

零依赖、零构建。任意静态服务器即可：

```bash
# 方式一：内置静态服务器
node tools/serve.mjs            # 默认 8080 端口

# 方式二：任意静态服务器
python3 -m http.server 8080
```

打开浏览器访问 `http://localhost:8080`，点击「进入宇宙」。

> 音频需要用户手势唤醒，因此首次播放由「进入宇宙」按钮触发。

## 🧪 测试

核心逻辑与引擎调度均附带自动化测试：

```bash
node --test test/composition.test.mjs    # 作曲核心：种子确定性、音阶、和声、动机、节奏
node --test test/visual.test.mjs        # 视觉引擎：四模式渲染冒烟
node --test test/audio-engine.test.mjs  # 音频引擎：fake AudioContext 驱动真实调度
```

共 18 项，覆盖种子确定性、和声闭环、欧几里得节奏、世界多样性、四模式渲染、调度器运行与演化等。

## 🏗 架构

```
index.html              页面结构与控制面板
css/style.css           深色玻璃美学界面
js/
  main.js               主控制器：装配引擎、绑定交互
  audio/
    composition.js      作曲核心（纯逻辑）：音阶、和声、动机、欧几里得节奏、世界观
    synth.js            声部合成器：pad / bell / bass / kick / hat / lead / shimmer
    effects.js          生成式混响、乒乓延迟、母带链
    engine.js           lookahead 调度器、声部调度、演化系统
    recorder.js         录音与 WAV 编码
  visual/
    palettes.js         调色板系统
    renderer.js         视觉引擎基座：画布、频谱分析、帧循环
    modes.js            四种视觉模式
    utils.js            流场噪声
test/composition.test.mjs  作曲核心测试
tools/serve.mjs         零依赖静态服务器
```

设计原则：**声画同源**——音乐与视觉共用同一颗种子的随机流，使得每一个宇宙在听觉与视觉上都自洽、可复现、可分享。

## 🌱 理念

星澜不是播放器，而是一台**宇宙发生器**。它不演奏任何曲目，而是为每一颗种子即时地"写"一首环境音乐，并为它配上一个独一无二、持续演化的光影世界。每一次按下「新宇宙」，都是一次无中生有的创世。
